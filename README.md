# Sistema de reservas de hotel

Proyecto final de Programación I. El sistema se desarrollará en Python.

## Organización

| Ubicación | Contenido |
| --- | --- |
| `main.py` | Punto de entrada e integración de los casos de demostración |
| `models/` | Hotel, habitaciones, cliente, estadía, reserva y factura |
| `exceptions/` | Excepciones propias del sistema de reservas |
| `controllers/` | Búsquedas y coordinación de las operaciones |
| `views/` | Interacción por consola |
| `docs/` | Diagrama UML y Documento de Decisiones de Diseño |

Ejecutar `python main.py` desde la raíz. La versión inicial solo muestra el nombre del sistema; la lógica se incorporará desde las ramas de trabajo.

## Trabajo en equipo

Traer la base de `main` antes de empezar y trabajar en una rama propia. Integrar cada aporte mediante un pull request.
